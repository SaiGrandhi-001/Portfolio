# Portfolio

Personal portfolio showcasing projects, tech stack, and contact links.

## About

This repository contains a personal portfolio website built with HTML, CSS, and JavaScript. It showcases projects, skills, and contact information in a clean, responsive layout.

## Features

- Project gallery with descriptions and links
- Responsive layout for desktop and mobile
- Contact section with links to social profiles and email
- Dark / Light theme toggle
- Accessible, semantic markup

## Run locally

1. Clone the repo:

   git clone https://github.com/SaiGrandhi-001/Portfolio.git

2. Open `index.html` in your browser, or run a local server:

   - Using Python 3:
     ```bash
     python -m http.server 8000
     # then open http://localhost:8000
     ```

   - Using VS Code Live Server extension: Open the folder and click "Go Live".

## Project structure

- `index.html` — main landing page
- `assets/` — images and media (if present)
- `css/` — stylesheet(s)
- `js/` — JavaScript files

Adjust paths to match your repository structure.
